# TaskFlow

Небольшое клиентское приложение для регистрации, входа и ведения личных задач. Сервер и установка зависимостей не нужны.

## Запуск

1. Откройте `index.html` в актуальной версии Chrome, Firefox или Edge. Все файлы из этой папки должны оставаться вместе.
2. Зарегистрируйте пользователя и войдите с его логином и паролем. Для проверки предустановленной учётной записи используйте `admin` / `Admin123`.
3. После входа откроется `tasks.html`. Здесь можно создать задачу, выполнить её, удалить или выбрать фильтр. Кнопка «Выйти» завершает сессию.

Данные пользователей, текущая сессия и задачи сохраняются в `localStorage` браузера. Они доступны только в том же браузере и профиле. Для чистого запуска удалите данные сайта в настройках браузера. В режиме приватного просмотра данные обычно исчезают после закрытия окна.

## Структура

- `index.html` — вход и регистрация;
- `tasks.html` — список задач;
- `css/style.css` — оформление;
- `js/auth.js` — регистрация и вход;
- `js/session.js` — проверка сессии и выход;
- `js/tasks.js` — создание, выполнение, удаление и фильтры;
- `docs/ТЗ_тестирование_ПР1.docx` — техническое задание.

Хранение паролей в `localStorage` соответствует учебному ТЗ, но не подходит для реального приложения с конфиденциальными данными: при таком использовании нужны серверная авторизация и защищённое хранение паролей.
